# 路线图
## 基本目标
### 一个简洁快速的教程
- 通用官方规则的简单介绍
- 深入的进阶教程资源链接
	- 出于个人水平的原因，暂时不计划制作系统性的进阶教程体系
- 历史背景和典故简介；文化溯源问题的复杂性的通俗阐释
- 为外国人优化
	- 国际化
		- 越南语
		- 英语
		- 俄语
		- 日语
		- 韩语
	- 通过其他棋类运动和竞技运动的热爱唤起关注
		- If you love chess or are just looking for a new strategy game, Xiangqi is a great choice for you!
	- 对国际象棋和中国象棋规则的相同之处进行讲解，不同之处直接看通用教程
### 技术说明
- 链接到本文档
- 链接到使用的技术
	- pikafish(gpl3)
### 性能和用户体验
- 运行十分流畅，界面也很简洁明了
- 一个硬件要求低的2D界面
- 更多的 Steam 成就系统奖励，那样就能增加游戏的趣味性以及重玩价值
- 深入全面的性能配置和规则配置
	- 【自定义规则可能不适用于AI，需要研究】
### AI
- 人工智能对手很有趣，能在不同难度级别上带来不错的挑战，让游戏过程既有趣又公平
